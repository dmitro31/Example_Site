# Example Site

A showcase website with ready-made example designs for small businesses. It demonstrates how a website could look for three types of business: a dental clinic, a café and a restaurant.

**Live demo:** https://example-site-jade.vercel.app

## What's Inside

- **Dental clinic** - a clean, trustworthy design for a medical business
- **Café** - a warm, friendly design for a casual place
- **Restaurant** - a more elegant design for a restaurant

Each design is a separate example, so a client can compare styles and choose the direction that fits their business.

## Tech Stack

- TypeScript
- Deployed on Vercel

## Getting Started

### Requirements

- Node.js 18+

### Run locally

```bash
git clone https://github.com/dmitro31/Example_Site.git
cd Example_Site
npm install
npm run dev
```

Open the address shown in the terminal in your browser.

### Production build

```bash
npm run build
npm run start
```
